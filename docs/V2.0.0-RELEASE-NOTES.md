# RaceLab v2.0.0

RaceLab v2.0.0 brings F1 25 and Forza Horizon 6 into one Windows telemetry app,
with automatic recording, mixed-game session history and a refreshed interface.

- **Multi-game architecture:** separate game adapters and recorders share one
  desktop app and session browser.
- **F1 25 live telemetry:** player telemetry, driver inputs, timing, tyre data
  and race context in game-specific views.
- **F1 recording and persistence:** sessions record automatically and retain
  lap, event and session data for later inspection.
- **Mixed-game Sessions:** browse and filter FH6 and F1 recordings together,
  with clear completion, interruption and recorder-ownership status.
- **F1 in-game overlay:** a compact, non-activating display with adjustable
  position, scale and opacity.
- **New RaceLab identity and redesigned UI:** updated app and installer icons,
  locally bundled Geist fonts and responsive Windows layouts across Home,
  Live, Sessions, Settings and Diagnostics.
- **Preserved FH6 support:** live telemetry, automatic recording, persisted
  sessions and existing analysis continue to work.

RaceLab runs locally without accounts or telemetry uploads. The Windows x64
package uses a per-user NSIS installer.

Advanced analysis, continuous telemetry traces and reference-lap comparison
remain future work and are not included in v2.0.0.
