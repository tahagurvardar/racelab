# RaceLab V0.3 — real telemetry capture validation

Implemented 2026-09-18 on Windows. V0.2.2 `src-tauri/src/ingress.rs` and `src-tauri/src/packet.rs` have no diff. Capture attaches through `Listener::new(ReceiveBuffer::default(), Some(capture))` in Tauri setup. The UDP loop, socket options, wake protocol and transport tests are unchanged.

The user's manual FH6 verification is recorded as supplied: port 20440, continuous 324-byte traffic, observed source 127.0.0.1:5200, approximately 70 packets/sec, zero receive errors. That verification applies to frozen ingress. No new real-game recording or manual WebView capture-button test was performed during this implementation. The six datasets remain to be recorded using [the collection guide](FIRST-SIX-FH6-DATASETS.md).

## Behavior and review

- `RawCaptureSink` owns a 4,096-frame bounded queue, explicit start/stop admission, a dedicated writer and capture-only summary state. Ingress does a bounded byte copy and `try_send`; none of its locks are held by disk I/O or writer joins.
- Overflow drops newest and increments `dropped_capture_frames`. A deterministic stalled-writer test fills the queue while the writer cannot proceed and verifies ingress completes before disk is released. A second test saves an overflowing capture and checks both the binary footer and JSON sidecar contain the exact loss count.
- Stop closes admission, drains accepted packets and syncs raw file and summary on a blocking worker. UI status stays provisional until Saved. Storage errors are returned/published; failed writes cause rejected frames to be counted until Stop. Files are preserved on error.
- Monotonic capture timestamps remain ordered across listener restart/wall-clock regression. Original ingress timestamps, source and bytes remain available. Replay is streaming, offline and unpaced.
- The UI adds one capture panel using existing styles, updates the version, and defaults to verified port 20440. Existing telemetry controls/metrics remain. Capture snapshots have increasing revisions to reject stale event/command replies. The React review checked effect cleanup, subscription-before-hydration, recovery, label association, disabled states, error/loss alerts and functional state updates.
- See [RLCAP v1](RAW-CAPTURE-FORMAT.md) for the binary format, timestamp semantics, queue memory bound, failure behavior, reader API and fixture workflow.

## Reproduce

Run build/test commands sequentially on Windows to avoid executable replacement contention:

```powershell
pnpm format:check
pnpm check
pnpm test:frontend
pnpm build
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
cargo test --manifest-path src-tauri/Cargo.toml -- --test-threads=1 --nocapture
```

Record game datasets with `pnpm tauri dev`, Start listener on 20440, an explicit capture label, Start Capture, then Stop Capture and wait for Saved. Storage is Tauri's local application data directory plus `captures`, normally `%LOCALAPPDATA%\com.tahagurvardar.racelab\captures`. The panel displays the full file path. Validate each file with the documented inspector and preserve its digest/observation notes.
